# Assets

**Art direction:** Industrial aerospace modernism. Near-black ultramarine, charcoal, smoked glass, muted copper, Perihelion Amber (`#F6A53A`) for powered systems, and restrained ice-cyan for environmental information. The world should read as a clean real-time voxel game, not a glossy cinematic illustration.
